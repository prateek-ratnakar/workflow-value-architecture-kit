# Process families

Each file gives the level-2 steps of one end-to-end workflow, the handoffs and exceptions that break it, the KPIs that show its health, and a first-pass view of the AI role per step (from `ai-readiness/`). The AI role is a starting hypothesis: inside a step, case-level guardrails still split automatic from human handling, as the prototype repo shows for deductions, collections and invoice exceptions.
